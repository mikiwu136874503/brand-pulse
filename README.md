# Brand Pulse · 竞争品牌内容雷达

用 AI 自动采集、分析竞争品牌内容，并生成可执行的内容策略包。

## 功能列表

1. **品牌内容采集** — RSS / 网页列表抓取；系统根据 URL 自动识别采集方式（含 `feed`/`rss`/`.xml` 等走 RSS，否则走网页解析），一键抓取标题、链接、摘要并去重入库
2. **AI 自动分类** — 案例研究 / 产品更新 / 行业洞察 / 技术博客 / 其他；支持单篇与批量分类
3. **AI 摘要生成** — 为每篇文章生成 100 字以内中文摘要；支持单篇与批量生成
4. **品牌调性分析** — 语气风格、高频关键词 Top 10、主题分布（饼图 + 表格）
5. **品牌对比** — 内容类型分布、近 3 个月发布频率、关键词交集与差异词云、**主题分布对比（需先对两品牌分别执行「分析品牌调性」）**
6. **差距分析** — 基于双品牌对比数据，AI 输出内容策略差异、优劣势与改进建议
7. **内容生成** — 基于差距分析生成公众号推文草稿、社交媒体短文案（3 条）、行业观点短文（3 篇）、7 天内容日历；支持一键复制

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY 和 DEEPSEEK_BASE_URL

# 3. 启动应用
python app.py
```

浏览器将自动打开 Streamlit 界面（默认 `http://localhost:8501`）。

也可使用：`streamlit run app.py`

## 使用路径

1. **添加品牌** — 在「品牌内容管理」填写品牌名称与 **RSS 地址 / 网页地址**
2. **采集** — 点击「立即采集」抓取最新文章（显示采集方式：RSS 或网页）
3. **分类 / 摘要** — 单篇或批量执行「AI 分类」「一键生成所有摘要」（需配置 API Key）
4. **调性分析** — 在「品牌对比分析」页上方，对目标品牌点击「分析品牌调性」（主题分布对比的前置步骤）
5. **双品牌对比** — 选择品牌 A、品牌 B，点击「开始对比」，查看类型分布、发布频率、关键词与主题分布对比
6. **差距分析** — 在对比结果页点击「生成差距分析」
7. **内容生成** — 在「内容策略生成」页基于已加载的差距分析结果，点击「生成内容策略包」

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 / 框架 | Python、Streamlit |
| AI | DeepSeek API（OpenAI 兼容接口） |
| 数据采集 | feedparser、requests、beautifulsoup4 |
| 存储 | SQLite |
| 可视化 | Plotly |
| 文本分析 | jieba、wordcloud、matplotlib |

## 环境变量

在项目根目录创建 `.env` 文件（可参考 `.env.example`）：

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥 | `sk-xxxxxxxx` |
| `DEEPSEEK_BASE_URL` | API 基础地址 | `https://api.deepseek.com/v1` |

未配置 API Key 时，品牌添加、内容采集与文章浏览仍可用；AI 分类、摘要、调性分析、差距分析与内容生成需配置后使用。
